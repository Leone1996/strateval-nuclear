# ChinaTalk publication copy

Prepared 30 September 2026. Suggested release tag: `v1.0-chinatalk`.

## Provenance

Source: the `Repo/Zip` subtree in the StratEval-Nuclear Prototype Drive folder.
An exact 116-file snapshot, including original caches, is preserved separately.
SHA-256 hashes, Drive file IDs and source modification times are recorded in
the accompanying original snapshot manifest.

The original Drive files have not been modified. This is a separate publication
copy, not a rewrite of the historical submission.

## Packaging changes

- Rename `strateval_pythonscripts/` to `crisiseval/`, matching existing imports.
- Omit 29 generated `.pyc` files and their cache directories.
- Remove API-key-prefix printing from five live-provider smoke-test scripts.
- Add `.gitignore`, an empty `.env.example`, release notes and a provenance
  section with a link to StratEval Situation Room.
- Change the README venv command to `python3` rather than `python3.11`.
- Record the tested dependency environment in `requirements-tested.txt` and
  source provenance in `SOURCE_SNAPSHOT.json`.

Application logic, evaluation logic, source cards, scenarios, treatments and
existing tests otherwise retain their original bytes.

## Project page

A separate static GitHub Pages preview is supplied in `docs/`, with fixtures
generated by `scripts/build_web_demo.py`. The preview offers all 160 original
scenario/treatment pairs, two mock profiles, COA paths, risk indicators, source
caveats, reasoning and case JSON downloads. The compressed fixture contains
outputs of the unchanged Python harness; no live provider calls were made.

The page links to the separate Situation Room project and to this repository.
Modern browser gzip decompression is used to load the compact fixture file.

## Validation

- Python 3.12. Original declared dependencies installed in an isolated venv.
- Existing test suite: **84 passed**.
- Streamlit AppTest: launch and default offline Run simulation completed with
  no app exceptions. No live provider calls were made.
- All Python files parsed and all JSON files decoded successfully.
- Credential-pattern scan found no matching keys; smoke utilities no longer
  print API-key prefixes.

`requirements-tested.txt` records the validation environment; the historical
